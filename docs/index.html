Unity Software

美股代码：U｜游戏引擎、实时3D、广告技术、AI

先说结论：

Unity 是一家有潜在护城河、正在重新证明商业模式的成长型软件公司，但目前还不能简单归类为便宜的价值股。

它最值得关注的变化是：2026年第三季度，Unity 的广告业务重新加速，营收增长、自由现金流改善，并且首次实现上市以来的单季度 GAAP 盈利。

不过，过去几年公司经历过战略失误、管理层调整和客户信任危机。现在的投资逻辑，很大程度上依赖新管理层能否持续兑现复苏。

以下按照你常用的巴菲特式价值投资框架分析，投资期限以3–5年为主。

一、公司究竟靠什么赚钱？

Unity 有两大核心业务。

1. Create：游戏开发工具

开发者使用 Unity 制作游戏、3D场景、汽车仿真和交互应用。

收入来源：软件订阅、企业授权及相关开发工具。

2. Grow：广告与游戏增长业务

帮助游戏开发商获取用户、投放广告、实现流量变现。

收入来源：广告投放、用户增长和广告技术服务。

最重要的是两项业务之间存在协同关系：

  • 开发者使用 Unity 制作游戏。
  • 游戏上线后，通过 Unity 的广告技术获取用户。
  • Unity 从开发工具和广告变现两个环节赚钱。

这是一种比较有价值的平台商业模式。

二、护城河分析

这是决定 Unity 是否值得长期持有的核心。

护城河评价分析
技术壁垒强游戏引擎技术积累深
用户网络效应较强开发者、插件、教程形成生态
转换成本较强游戏项目迁移引擎成本高
品牌影响力强全球开发者熟悉 Unity
规模经济中等广告数据和技术规模越大越有优势
定价权中等开发者对价格和收费政策敏感
客户黏性较强已经上线的游戏不容易随意更换引擎

主要竞争对手

Unity

优势：移动游戏生态、跨平台开发、中小团队开发工具。

Unreal Engine

优势：高端3D画面、主机游戏、AAA游戏开发。

Godot

优势：免费、开源、社区发展迅速。

我的判断：

Unity 最大的竞争优势不是它的画面比别人好，而是它已经融入大量开发者的工作流程。

但护城河并非不可攻破。

尤其是 Unreal 和 Godot，如果不断提升易用性，Unity 的定价权可能受到挑战。

我认为 Unity 的护城河属于中等偏强，而不是微软、谷歌那种拥有极强生态控制力的护城河。

我最关注的三个指标

1. Grow业务增长90%

这是本次财报最大的亮点。

Unity 的广告技术正在恢复增长，尤其是 AI 驱动的 Vector 广告平台。

Vector 是值得持续观察的业务，因为它直接影响 Unity 能否重新建立广告市场竞争力。

2. Create业务增长11%

这一块反而没有特别惊艳。

游戏开发工具是 Unity 的根基，但增长速度远远低于广告业务。

如果未来 Create 长期只有个位数增长，Unity 的长期竞争力需要重新评估。

Unity 过去最大的问题就是费用太高。

这里有一个值得警惕的问题：

Unity 是一家毛利率很高的软件公司，但是研发、销售和管理费用曾经吞噬了大量毛利润。

这意味着：

  • 产品本身具备高毛利特征。
  • 规模扩大后有机会产生很强的经营杠杆。
  • 但如果收入增长停止，庞大的研发和人员成本会重新压缩利润。

我希望未来看到：

  • 毛利率稳定在70%以上。
  • 研发费用占营收比例持续下降。
  • 销售及管理费用增长低于营收增长。
  • GAAP营业利润持续转正。
  • 自由现金流增长不是依靠一次性营运资金变化。

Unity 过去的管理层问题非常值得警惕。

尤其是此前 Runtime Fee 收费政策引发开发者强烈反对，严重伤害了客户信任。

对于游戏引擎公司来说，开发者信任就是核心资产。

我对当前管理层的评价：

维度评价
战略调整有积极改善
成本控制明显改善
广告业务出现强劲增长
开发者关系仍需修复

我不会因为一个季度的优秀财报就认定管理层已经优秀。

至少需要连续几个季度验证。

  • 现金、现金等价物及受限现金：约26.51亿美元。

  • 2026年到期债券需要偿还或处理。

这里有两个需要注意的地方：

第一，现金储备比较充足。

现金流转正后，公司对外部融资的依赖程度有所下降。

第二，可转债和股权稀释不能忽视。

Unity 存在2027年及2030年到期的可转换债券。公司还存在股权激励和股份数量变化。

因此，分析每股价值时，不能只看企业总价值，还要关注完全摊薄后的股份数量。

1. 为什么不能只看 PE？

Unity 刚刚实现单季度 GAAP 盈利，TTM净利润仍然为负。

所以当前 PE 并不是可靠的估值工具。

我更倾向于使用：

  • EV/FCF
  • P/FCF
  • FCF利润率
  • 未来5年自由现金流增长率

目前约34倍年化FCF，并不便宜。

八、一个非常重要的新变量：潜在收购

2026年11月5日，路透社报道：

Silver Lake 和沙特公共投资基金 PIF 曾与 Unity 就收购进行接触，讨论过约250亿美元的估值。

但截至报道时：

  • 没有确定收购协议。
  • 没有确定交易价格。
  • Unity 正在评估相关方案。
  • 最终交易可能不会发生。

这件事对投资判断很重要。

如果250亿美元成为最终收购估值，以约4.44亿股粗略计算，相当于每股约56美元的股权价值。

但是，不能把潜在收购价当作确定的内在价值。

我不建议为了收购预期追涨。

如果收购失败，股价可能重新回到基本面估值。

但 AI 也可能让新的开发工具更容易进入市场，削弱传统游戏引擎的竞争优势。

这是一把双刃剑。

如果我是你，我会怎么做？

考虑到你的投资期限通常是3–5年，而且希望追求较高年化回报，我会这样处理：

  • 暂时不在50美元附近追涨。
  • 重点跟踪 Vector 广告业务能否持续增长。
  • 等待至少两个季度验证 GAAP 盈利和自由现金流。
  • 如果股价回到30美元附近，重新评估安全边际。
  • 即使买入，也不把 Unity 当作核心重仓股。

最后一个关键问题

我认为 Unity 有机会成为一家优秀的软件平台公司，但它还没有证明自己能够持续稳定地创造股东价值。

它值得进入观察名单，但目前我更愿意等待估值和经营质量同时给出机会。

我的投资优先级是：先验证商业模式，再判断管理层，最后才是估值。
